## 功能

幾乎不用多點幾下，就能查到列車狀態與到站時間：

- 台鐵時刻表查詢
- 台鐵即時到站查詢
- 下一班列車快速查看
- 常用目的地設定
- 班次與抵達時間快速分享

## 安裝成 App

### iOS（Safari）

1. 用 Safari 開啟 [ontrack.hsichen.dev](https://ontrack.hsichen.dev/)
2. 點底部分享按鈕
3. 選擇「加入主畫面」

### Android（Chrome）

1. 用 Chrome 開啟 [ontrack.hsichen.dev](https://ontrack.hsichen.dev/)
2. 點右上角 ⋮ 選單
3. 選擇「加到主畫面」或「安裝應用程式」
