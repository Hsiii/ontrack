## 這是什麼

OnTrack 是一個以手機使用為主的台鐵查詢工具，提供：

- 台鐵時刻表查詢
- 台鐵即時到站查詢
- 下一班列車快速查看
- 常用目的地設定
- 班次與抵達時間快速分享

如果你平常會搜尋「台鐵時刻表」、「台鐵查詢」、「台鐵即時到站」或「台鐵列車時刻」，這個 app 的目標就是把這些操作壓縮成幾個直覺步驟，減少每天重複點選的成本。

資料來源使用 [TDX](https://tdx.transportdata.tw/)，並針對手機使用情境做了 PWA 體驗與分享流程優化。

## 安裝成 App

### iOS（Safari）

1. 用 Safari 開啟 [ontrack.hsichen.dev](https://ontrack.hsichen.dev/)
2. 點底部分享按鈕
3. 選擇「加入主畫面」

### Android（Chrome）

1. 用 Chrome 開啟 [ontrack.hsichen.dev](https://ontrack.hsichen.dev/)
2. 點右上角 ⋮ 選單
3. 選擇「加到主畫面」或「安裝應用程式」
