## 功能

- 自動偵測最近車站
- 自動填入預設目的地
- 自動計算延誤以顯示下一班列車
- 班次與抵達時間快速分享

## 從網頁安裝 App

### iOS（Safari）

1. 用 Safari 開啟 [ontrack.hsichen.dev](https://ontrack.hsichen.dev/)
2. 點底部分享按鈕
3. 選擇「加入主畫面」

### Android（Chrome）

1. 用 Chrome 開啟 [ontrack.hsichen.dev](https://ontrack.hsichen.dev/)
2. 點右上角 ⋮ 選單
3. 選擇「加到主畫面」或「安裝應用程式」
