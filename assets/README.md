# Assets

Root-level release and marketing assets that are not app build inputs.

- `app-store/screenshots`: App Store screenshots generated by `bun run ios:screenshots`.

The iOS asset catalog stays in `apps/ios/OnTrack/Assets.xcassets` because Xcode consumes it when building the app.

OnTrack logos, icons, screenshots, and App Store materials are brand assets.
